# Project background

## 项目定位

这是 Frank 的中文个人技术知识站，公开地址为 `https://knowledge.webfrank.top/`。它把技术笔记、自动化实践、AI Agent / AI 编码研究、Web / React 与 RPA / Playwright 经验整理为可检索、可导航、可持续发布的 VitePress 内容库。

## 目标用户

- 主要用户：作者本人，用于长期知识沉淀、复盘与复用。
- 公开读者：关注中文技术实践、自动化和 AI 工程的开发者。
- 维护参与者：人工开发者与遵循项目契约的 Coding Agent。

## 已有目标

- 让专题文章、博客、精选阅读和资源页通过统一导航被发现。
- 保持技术正文的可读性，同时建立稳定、可验证的视觉系统。
- 让内容新增、索引同步、设计检查、构建和发布形成机械化流程。
- 对部分研究型内容保留可复核实验材料，见 [[repository-owned-agent-benchmark]]。

## 明确边界

- `README.md` 是站点导航，不是部署指南，见 [[generated-readme-navigation]]。
- 站点不维护第二套自定义主题模式，见 [[single-editorial-site-experience]]。
- 生成产物 `docs/.vitepress/dist/` 不作为手工维护源。
- 项目不是通用 CMS；内容源以仓库内 Markdown、Vue 主题组件和静态资产为主。

## 置信度

项目定位和现有边界由 README、`DESIGN.md`、目录结构与项目契约直接支持。更长期的商业目标、读者增长目标或内容 KPI 没有仓库证据，暂不推断。
