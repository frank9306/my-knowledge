# Changelog

Create one `YYYY-MM.md` file per month when an Issue is completed or cancelled. Record the delivered outcome under `Added`, `Changed`, `Fixed`, `Removed`, `Security`, `Documentation`, or `Cancelled`, and link back to the Issue.

This directory is the only Changelog source of truth. Historical entries migrated from the former root `CHANGELOG.md` retain their original release headings and are explicitly marked when they predate local Issue tracking.
